webp-natives

Public Maven repository for copyandexecute/webp-natives. No auth required. Backed by Google libwebp via JNI.

Aggregator (recommended — one dep, all platforms)

repositories {
    maven("https://copyandexecute.github.io/webp-natives/")
}
dependencies {
    implementation("gg.norisk.webp:all:<VERSION>")
}

Pulls in core + windows (DLLs x64/arm64) + linux (.so x64/aarch64) + macos (universal dylib). At runtime, gg.norisk.webp.WebP picks the matching native from the classpath via NativeLoader.

Individual modules

implementation("gg.norisk.webp:core:<VERSION>")
implementation("gg.norisk.webp:windows:<VERSION>")
implementation("gg.norisk.webp:linux:<VERSION>")
implementation("gg.norisk.webp:macos:<VERSION>")
